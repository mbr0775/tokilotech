# TokiloTech project preferences

- Treat SEO as a requirement whenever creating or changing website code or design. The owner wants better organic search visibility.
- Use useful, accurate service content, descriptive page titles and descriptions, correct canonical URLs, crawlable links, semantic headings, and meaningful image alt text.
- Keep primary content available in server-rendered HTML. Do not make essential content depend on autoplay, animation, or user interaction.
- Preserve fast loading, responsive layouts, stable image dimensions, keyboard access, and reduced-motion support.
- Choose recognizable icons that clearly match their concept or action, with a consistent style. Keep icons legible during 3D animation and reserve link arrows for actual links.
- For section background videos, use existing publicly hosted footage URLs rather than creating or generating video assets unless the owner explicitly requests generation.
- Use structured data only for facts actually supported by the website. Do not invent reviews, clients, results, locations, or awards, and do not promise search rankings.
- Verify changed routes and image loading, plus relevant lint, type, and build checks. Preserve existing uncommitted work.
